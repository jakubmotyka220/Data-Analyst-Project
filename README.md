# Data Analyst Project Airbnb

Projekt koncentruje się na kompleksowej analizie danych dotyczących ofert Airbnb w Nowym Jorku. Głównym celem było zrozumienie zależności między ceną noclegu a kluczowymi zmiennymi, takimi jak np. lokalizacja, typ obiektu oraz opcje rezerwacji. Wykorzystując autorski wskaźnik Possibility Profit, zidentyfikowałem najbardziej dochodowe dzielnice. Analiza obejmuje przygotowanie danych oraz przedstawienie wyników zarówno za pomocą raportu jak i wizualizacji w Tableau.

Tableau.txt - link do dashboardu w Tableau Public.

projekt.py - główny skrypt Pythona do oczyszczenia danych, analizy oraz przygotowania danych do wizualizacji.

Rynek nieruchomości w Nowym Jorku.pptx - raport podsumowujący analizę oraz przedstawiający kluczowe wnioski.
